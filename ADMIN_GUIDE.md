# Инструкция администратора

## Назначение

Администратор может добавить город с метро через кнопку «Администрирование». Схема загружается из OpenStreetMap, преобразуется в формат проекта и сохраняется в PostgreSQL.

Каталог в поле города содержит >180 рекомендуемых городов: крупные системы мира и все основные действующие системы России. Каталог является списком для проверки, а не ограничением: можно ввести любой другой город.

Если нужно подготовить каталог заранее, используйте скрипт `scripts/download-catalog.ps1`: он последовательно обрабатывает города, повторяет неудачные запросы и сохраняет только успешно полученные схемы в `backend/data/imports`.

## Запуск

В первом окне PowerShell запустите базу и миграции:

```powershell
cd "C:\Users\HONOR\OneDrive\Desktop\учеба\подземка проект\podzemka"
docker compose up -d db
docker compose --profile tools run --rm migrate
```

Во втором окне запустите backend:

```powershell
cd "C:\Users\HONOR\OneDrive\Desktop\учеба\подземка проект\podzemka\backend"
$env:DATABASE_URL = "postgres://podzemka:podzemka@localhost:5433/podzemka?sslmode=disable"
$env:ADMIN_TOKEN = "dev-token"
$env:OSM_CONTACT_EMAIL = "you@example.com"
go run ./cmd/api
```

В третьем окне запустите frontend:

```powershell
cd "C:\Users\HONOR\OneDrive\Desktop\учеба\подземка проект\podzemka\frontend"
npm run dev
```

## Добавление города

1. Откройте http://localhost:5173.
2. Нажмите «Администрирование».
3. Введите значение `ADMIN_TOKEN`.
4. Введите название города на русском или английском языке. Можно выбрать город из подсказок каталога.
5. Нажмите «Найти станции» и дождитесь предпросмотра.
6. Проверьте количество станций и линий.
7. Нажмите «Добавить на сайт».
8. Выберите новый город в списке городов.

## Пакетная подготовка каталога

Запустите backend, задайте токен и выполните из корня проекта:

```powershell
$env:ADMIN_TOKEN = "dev-token"
.\scripts\download-catalog.ps1
```

Из-за ограничений публичных OSM-сервисов часть городов может завершиться ошибкой. Скрипт не удаляет уже существующие файлы и повторяет неудачные запросы. После успешной загрузки JSON-файлы можно добавить в Git и использовать для локального импорта без Overpass.

## Важные ограничения

- Один город нельзя добавить повторно: backend проверяет название и slug.
- Пустая схема не сохраняется.
- Для импорта нужен доступ к Nominatim и Overpass API.
- Если OSM отвечает медленно, повторите операцию позже или настройте `NOMINATIM_URL` и `OVERPASS_URL` в `backend/.env`.
- Проверяйте результат импорта: порядок станций и принадлежность станций к линиям восстанавливаются автоматически и могут требовать ручной проверки.
- Для названий станций импортёр выбирает `name:ru`, затем `name:en`, международное название и только потом исходное `name`. Уже сохранённые JSON-файлы автоматически не меняются: их нужно заново получить из исходного Overpass JSON и повторно импортировать.

## Удаление ошибочных записей

Сначала найдите города с пустыми схемами:

```powershell
docker compose exec db psql -U podzemka -d podzemka -c "SELECT c.id, c.name, c.slug, jsonb_array_length(m.schema->'stations') AS stations, jsonb_array_length(m.schema->'lines') AS lines FROM cities c LEFT JOIN metro_schemas m ON m.city_id = c.id ORDER BY c.id;"
```

При удалении строки из `cities` связанная схема удаляется автоматически.
